# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Added
- Intro/outro video concatenation with configurable transitions
- Support for Crossfade, Hard Cut, and Fade to Black transitions
- Optional intro/outro audio inclusion
- Preview support for combined videos
- pytest test suite for concatenation logic
- Resolution auto-scaling with letterboxing for aspect ratio mismatches

### Changed
- Added new UI controls for intro/outro video settings
